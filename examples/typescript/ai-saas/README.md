# ai-saas (TypeScript) — metering an AI product

The SynapseDev.AI shape from TypeScript: metered inference calls, quota
breaches as typed errors you can bill around.

## Run

```bash
export SYNAPSE_API=http://localhost:8000
export SYNAPSE_KEY=sk_…   # an API key for the org (console → API keys)

cd examples/typescript/ai-saas
pnpm install && pnpm start
```
